Diffie-Hellman

Practical implementation and study of Diffie-Hellman key exchange for establishing a shared secret using public-key cryptography concepts. Participants publish public values derived from a private secret; they do not “create a public key” as the primary goal — they agree on a shared secret over an untrusted channel.

  • Diffie-Hellman
  • Public-key concepts
  • Shared secret

Outcome: A clearer understanding of how two parties derive a shared secret without transmitting that secret directly.

Diffie-Hellman key exchange

Diffie-Hellman lets two parties compute a shared secret over a public channel. Each party keeps a private value and publishes a related public value. Combining the peer’s public value with one’s own private value produces the same shared secret on both sides.

This project studies that process as a cryptography concept. It does not claim that Diffie-Hellman “creates a public key” as its end result; the practical goal is a shared secret used in a public-key setting.
